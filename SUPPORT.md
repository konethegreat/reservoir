# Getting help

- **Questions, ideas, introductions:** [GitHub Discussions](https://github.com/konethegreat/reservoir/discussions)
- **Bugs and feature requests:** [Issues](https://github.com/konethegreat/reservoir/issues/new/choose)
- **Security issues:** see [SECURITY.md](SECURITY.md) — never in public
- **Cultural-sensitivity concerns:** use the *Cultural sensitivity / takedown* issue template, or report privately if the content itself is sensitive
- **Docs:** start at [`docs/index.md`](docs/index.md)

Reservoir is pre-alpha and volunteer-run; please be patient and kind.
