# data

Taxonomies, manifests and **synthetic** seed/example data.

> ⚠️ **No real community knowledge, personal information or audio belongs in this repository.** Real data lives only in the access-controlled production system. Local development data goes in `data/local/` (git-ignored).

- `seed/` — clearly marked examples that illustrate the schema. Anything under `seed/` is placeholder content unless a file states otherwise and cites its source and licence.
- Dataset manifests (future) record source, licence and checksum for every imported dataset. See [data sources](../docs/research/data-sources.md).
